Biblioteca Escolar

Biblioteca Escolar

2026 Desarrollo Full Stack Proyecto académico - Fundación Kinal

Biblioteca es una aplicación web para la gestión de una biblioteca escolar, desarrollada como proyecto académico. Permite administrar libros, materias/cursos y su moderación de contenido, con una arquitectura basada en microservicios.

Descripción del proyecto

El proyecto de biblioteca tiene como objetivo el poder ayudar a estudiantes de la institución kinal, para poder subir y asi tener una recopilación de contenido retroalimentivo de cada curso, esto para que los alumnos puedan usarlo de apoyo para estudiar o para retroalimentarse.

Habilidades aprendidas / aplicadas

  • Arquitectura de microservicios (files-service y moderation-service)
  • Backend con Node.js, Express y MongoDB
  • Frontend con React (Vite)
  • Manejo de subida de archivos (Cloudinary)
  • Integración de frontend y backend vía API

Implementación técnica

El proyecto está dividido en servicios independientes: un servicio de archivos (`files-service`) construido con Node.js, Express y MongoDB, un servicio de moderación de contenido (`moderation-service`), y un frontend en React con Vite que consume ambas APIs.
