Veterinaria

2025 Desarrollo de Escritorio / Java Proyecto académico - Fundación Kinal

Veterinaria es una aplicación de escritorio para la gestión integral de una clínica veterinaria, desarrollada como proyecto académico con Java y JavaFX.

Descripción del proyecto

El sistema está dirigido al personal de una clínica veterinaria. Permite gestionar clientes y sus mascotas, citas, consultas, tratamientos, vacunación (con cartilla imprimible), recetas, facturación, compras, proveedores y empleados, todo desde una interfaz de escritorio.

Habilidades aprendidas / aplicadas

  • Desarrollo de interfaces de escritorio con JavaFX (FXML)
  • Arquitectura MVC (bean / controller / view)
  • Generación de reportes en PDF con JasperReports
  • Persistencia en MySQL con JDBC

Implementación técnica

El proyecto sigue una arquitectura MVC: los bean representan las entidades (clientes, mascotas, citas, etc.), los controller manejan la lógica de negocio, y las vistas están construidas en JavaFX con archivos FXML. Los reportes (facturas, cartilla de vacunación) se generan con JasperReports, y los datos se persisten en MySQL.
