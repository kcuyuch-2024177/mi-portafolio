Renta de Casas

2025 Desarrollo Backend / Java EE Proyecto académico - Fundación Kinal

Renta de Casas es un sistema web de reservas de hospedaje (similar a Airbnb), desarrollado como proyecto académico. Permite administrar propiedades, reservas, pagos y usuarios con distintos roles, sobre una arquitectura MVC en Java.

Descripción del proyecto

El sistema está dirigido a administradores y clientes que buscan reservar hospedaje. Permite publicar propiedades, gestionar reservas y pagos, y administrar servicios adicionales (spa, transporte, restaurante, entre otros) desde un panel administrativo.

Habilidades aprendidas / aplicadas

  • Arquitectura MVC en Java (Servlets + JSP)
  • Patrón DAO para acceso a datos
  • Persistencia en MySQL con JDBC
  • Despliegue sobre servidor de aplicaciones GlassFish

Implementación técnica

El proyecto usa Servlets como controladores y JSP para las vistas, con clases DAO dedicadas para cada entidad (usuarios, propiedades, reservas, pagos) y conexión directa a MySQL vía JDBC. Se ejecuta sobre el servidor de aplicaciones GlassFish.
